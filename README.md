# Medical Insurance Cost Prediction

## Overview
This project predicts medical insurance costs based on user information such as age, gender, BMI, number of children, smoking status, and region using Machine Learning.

## Features
- Predicts medical insurance charges
- Data preprocessing and analysis
- Machine Learning model for prediction
- User-friendly Jupyter Notebook implementation
- Data visualization

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Input Parameters
- Age
- Gender
- BMI
- Number of Children
- Smoking Status
- Region

## Output
- Predicted Medical Insurance Cost

## How to Run
1. Install the required Python libraries.
2. Open `finalproject.ipynb`.
3. Run all notebook cells.
